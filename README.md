## 🌌 Overview

**AARUUSH QUEST** is an interactive cyberpunk festival speedrun challenge built for SRMIST's national-level techno-management fest, **Aaruush**. 

Players dive into an interactive holographic grid map, racing against a **180-second countdown timer** to breach portals across **17 specialized technical, design, and managerial domains**.

## ✨ Features

- **⚡ 180s Real-Time Countdown**: Fast-paced speedrun format keeping players on the edge.
- **🎯 85 Curated MCQs**: 5 unique, authentic domain-tailored questions for all 17 domains.
- **⚡ Snappy 750ms Auto-Advance**: Fast transition between questions with zero downtime for both correct and wrong answers.
- **💾 Real-Time Breach & Scoring**: Scores, streaks, and portal completions are instantly committed upon answering.
- **📊 Live Grid Telemetry Screen**: Full interactive telemetry dashboard showing real-time ranking, accuracy metrics, and domain breach statuses.
- **🔊 Cyber Audio Synthesizer**: Web Audio API sound effects for clicks, correct answers, wrong answers, countdown ticks, and victory sequences.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

## 🚀 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/adityaswaroop1100-jpg/AARUUSH-QUEST.git

# Navigate into the project folder
cd AARUUSH-QUEST

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Build & Deploy
```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
